## APIs used

- YouTube Data v3 API

## Running the abominations locally

### Prerequisties

- Node.js v22 or higher (LTS recommended)
- pnpm

### Setup and installation

After cloning, install dependencies with `pnpm`:

```console
pnpm install # or pnpm i
```

Run the dev server

```
# Dev server
pnpm run dev
```

```console
# Linting
pnpm run lint

# Format and fix code conventions
pnpm run lint:fix
```
