## Running the abominations locally

### Prerequisties

- Node.js v22 or higher (LTS recommended)
- Yarn package manager

### Setup

After cloning, install dependencies with `yarn`:

```bash
yarn install
```

#### Website

Start the a dev server with:

```
yarn dev
```

Which exposes <http://localhost:4321>.
